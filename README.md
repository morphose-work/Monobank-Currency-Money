# 📊 Почасовой мониторинг курсов валют в n8n

Это автоматизация ежечасно отправляет актуальный курс **USD** и **EUR** с помощью публичного API **Monobank** и отправляет красивый ответ в **Telegram**

## 🛠 Стек технологий
- **n8n** 
- **Monobank API**
- **Telegram Bot API**
- **JavaScript / Node.js**

## 🏗 Как работает воркфлоу
1. **Schedule Trigger:** Запускает сценарий каждый час
2. **HTTP Request:** Делает бесплатный публичный GET-запрос к `https://api.monobank.ua/bank/currency`.
3. **Code (JavaScript):** Фильтрует данные и делает красивым ответ
4. **Telegram Node:** Отправляет ответ в Телеграм Бота

## 🚀 Как запустить его у себя?
1. Сделайте своего Телеграм Бота [@BotFather](https://t.me/BotFather) и получите **API Token**.
2. Узнайте свой **Chat ID** (например, через [@userinfobot](https://t.me/userinfobot)).
3. Скачайте файл `Currency Money.json` с этого репозитория.
4. Откройте ваш n8n, создайте новый воркфлоу и выберите **Import from File** в меню (три точки вверху).
5. В ноде **Telegram** настройте ваши `Credentials` (вставте токен бота) и укажите ваш `Chat ID`.
6. Активируйте воркфлоу! 📈
